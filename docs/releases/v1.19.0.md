# La Oficina v1.19.0

**Los agentes ahora respetan de verdad el `CLAUDE.md` de cada proyecto.**

Si añades un proyecto que ya trae sus propias reglas, se aplican. Y si ese proyecto vive dentro de un workspace que tiene su propio `CLAUDE.md` —con un protocolo de contexto, reglas o skills— **también se aplica ese**, sin que uno tape al otro.

## Qué pasaba

El archivo sí se cargaba. El problema es que Claude Code carga el del directorio **y los de todas las carpetas superiores**, y los aplica todos sin jerarquía entre ellos.

Probado con uno arriba pidiendo empezar por «LORO» y otro en el proyecto pidiendo «TUCAN»: la respuesta salía **«TUCAN LORO»**, intentando contentar a los dos. Y cuando el de arriba trae un protocolo largo, se lleva la atención y las reglas del proyecto quedan diluidas.

## Qué se hizo

Pedir la prioridad en una frase **no basta**: de dos intentos se cumplió uno. Lo que funciona es repetir el contenido de los `CLAUDE.md` dentro de las instrucciones del agente, **en orden: primero los de arriba, y el del proyecto al final** — por ser lo último leído, es lo que pesa.

Resultado, verificado tres veces seguidas: se cumplen **los dos**, y donde se contradicen gana el del proyecto.

## Detalles

- Cada mensaje lleva las reglas de **su** proyecto: con varias pestañas en proyectos distintos no se mezclan.
- Se leen **en cada mensaje**: si editas el `CLAUDE.md` a media conversación, el cambio entra en el siguiente.
- Con un tope, porque esto viaja siempre. Si no cabe todo, **se sacrifica lo de arriba**: las reglas del proyecto son las que no pueden faltar. Lo recortado avisa y dice cómo leer el resto.

## Cuál descargar

Si ya tienes La Oficina, **no descargues nada**: te avisará.
